# 두더지 팡팡 — 설계 문서

13번째 게임. 바닥 6개 구멍에서 랜덤으로 올라오는 귀여운 두더지를
손을 위로 올렸다가 내려쳐서 잡는 60초 챌린지 게임.

## 기본 정보

- id `mole`, 번호 13, 이름 `두더지 팡팡`
- 한줄 규칙: 바닥 6개 구멍에서 올라오는 두더지를 손을 위로 올렸다가 내려쳐서 잡아요.
- 운동 효과: 어깨 스트레칭 · 순발력
- 얼굴 마스크: 그리지 않음 (`hideFace`, 하단 구멍·두더지 시인성)
- 구현: `src/games/mole/mole-whack.ts` (`MoleWhack`), 등록은 `games/index.ts`·`ui/app.ts`·`ui/router.ts`

## 화면 구성

- 스테이지 하단에 땅 라인 (`height - 20`, 좀비 스텝과 같은 높이·색).
- 땅 위에 구멍 6개를 바닥 1열로 균등 배치: `x = width × (i×2+1)/12`.
- 타격 가능한 두더지(올라오는 중·올라와 있음)의 구멍에는 노랑 점선 발광 표시.
- 상단: `N마리 잡았어요 · 놓침 M` + `손을 어깨 위로 올렸다가 내려쳐요!` 안내.
- 오른쪽 위: 양손 무장 표시 (노랑=내려치기 가능, 회색=먼저 손을 올려야 함).
- `prefers-reduced-motion`에서는 구멍 발광을 끈다.

## 두더지 상태

```
HIDDEN → RISING → VISIBLE → FALLING → HIDDEN (놓침, 콤보 리셋)
              ↘ HIT(깜짝 표정) → HIDDEN (잡음, +10점·콤보+1)
```

- 스폰: 빈 구멍 중 직전 슬롯을 피해서 랜덤으로. 같은 곳 연속 출현 없음.
- 스폰 간격으로 조절되며, 30초 전에는 최대 1마리, 30초 이후에는 최대 2마리 동시 출현.
- 올라와 있는 동안 못 잡으면 내려가며 `miss` (감점 없음, 콤보만 리셋).
- 맞은 두더지는 `><` 눈·`O` 입·진한 볼의 깜짝 표정 + 머리 위 별 3개로 0.35초간 내려감.

## 손 타격 판정 (핵심 규칙)

손마다 무장 상태를 둔다 (수학 퀴즈 양손 리암 패턴 재사용):

1. 손목이 어깨보다 20px 이상 위에 올라가면 그 손이 무장됨 (한 번 무장되면 내려가도 유지).
2. 무장된 손이 두더지 머리(반경 56px, 별잡기·분리수거와 동일) 안에서
   아래로 내려오는 중(하강 속도 80px/s 이상)일 때만 타격 인정.
3. 아래에서만 움직인 손(무장 안 됨)은 두더지에 닿아도 타격 불가.
4. 가만히 대고 있어도(하강 속도 부족) 타격 불가 — 반드시 내려쳐야 함.
5. 타격 후 무장은 소모되어 다음 두더지를 잡으려면 손을 다시 올려야 함.
6. 손이 잠깐 안 보여도(깜빡임) 무장은 유지되고 속도는 리셋되어 오판하지 않음.

## 난이도 곡선 (60초 기준 선형 가속)

| 항목 | 시작 (0초) | 종료 (60초) |
|---|---|---|
| 올라와 있는 시간 | 1100ms | 450ms |
| 올라오기·내려가기 | 350ms | 150ms |
| 스폰 간격 | 1100ms | 500ms |
| 동시 출현 | 최대 1마리 | 최대 2마리 (30초부터) |

## 점수·효과음

- 두더지 1마리 = 10점 + 콤보 보너스 (`ScoreBoard` 공통).
- 잡음 이벤트 `catch` → 축하 파티클 + `hit` 효과음 (루프 공통 `CELEBRATE` 매핑).
- 놓침 이벤트 `miss` → 감점 파티클 + `miss` 효과음 (공통 `PENALTY` 매핑, 점수 차감 없음).
