# 업데이트 내역

> 운영 규칙 (프로젝트 메모리): 앞으로 수정이 있을 때마다 이 파일 맨 위에
> `## YYYY-MM-DD` 섹션을 추가하고, 같은 내용을 `CHANGELOG.md`에도 기록한다.
> 커밋·푸시·배포할 때는 이 두 파일의 변경분을 반드시 함께 포함한다 (빠뜨린 채 배포하지 않는다).
> '관리자 모드' 관련 내용은 업데이트 내역에 기록하지 않는다.
> 앱의 업데이트 모달과 게임 방법 모달은 이 파일과 `src/ui/help.ts`를
> 데이터로 읽으므로, 문서 수정만으로 화면에 반영된다.
> 같은 날짜에 추가할 때는 새 섹션을 만들지 말고 해당 날짜 섹션에 항목을 덧붙인다.
