# Skeleton Play — 카메라 운동 게임

랩탑·태블릿·크롬북 카메라로 즐기는 스켈레톤 운동 게임 4종. 설치 없이 브라우저에서 동작합니다.

## 시작

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:5173/#/fruit` 접속. 카메라 권한을 허용하세요.

## 게임

- `#/fruit` 과일 닌자 몸버전: 손(커서)으로 과일 베기, 폭탄은 건드리지 않기 (-15점)
- `#/squat` 스쿼트 러너: 앉았다 일어서기 반복
- `#/math` 점프 수학 퀴즈: 정답 구역으로 이동 + 손들기
- `#/abc` 몸으로 ABC: T·Y·O·L 순서대로 포즈 1초 유지

## 조작법

- 카메라: 화면 중앙에 전신이 보이게 1.5~2.5m
- 카메라 선택: 게임 화면의 드롭다운에서 사용 카메라 변경 (선택 저장됨)
- 카메라가 없으면: “카메라 다시 찾기” 버튼으로 재인식 시도
- 보정: 시작 시 T자세 3초, 스킵 시 앉음 모드 기본값

## 트러블슈팅

- 카메라 거부됨 → 게임 화면에 안내 + “카메라 다시 찾기” 버튼 표시
- 끊김 → 저사양 모드 토스트 확인, 조명을 밝게
- 모델 로드 실패 → 최초 1회는 온라인 필요 (CDN), 이후 PWA 캐시
